# Capri 1.1.1

- Reduced memory use in OpenClaw, Settings and the conversation renderer. Capri loads the active interface language on demand, renders conversation history when it opens and releases the Settings window after one minute in the background. The memory model warms up when the memory skill is enabled. Voice playback passes PCM buffers between processes and releases unused model components where supported.
- Fixed a Windows issue that could trap the desktop avatar when a window it was attached to was maximized. The avatar detaches and returns to the screen.
- A local voice timeout now affects the current reply and keeps the voice ready for another attempt. Diagnostic reports retain the stage of startup, model loading or speech synthesis. The CUDA report also reflects CPU voice support.
- Voice setup fetches pinned Git dependencies using the Windows certificate store. This avoids stale Git certificate paths left by a previous Git installation.
- Music listening detects beats more reliably when playback is quiet or vocals obscure the bass pulse.
- Added a Cyberpunk 2077 theme, a custom panel color and a background brightness control. The Cyberpunk preset uses cyan outlines and dark blue controls on a dark red and black background.

Run **CapriSetup-1.1.1.exe** and select your existing Capri installation folder to keep your settings, history and compatible models. The Windows installer is unsigned. SHA-256 checksums are included with the release.
