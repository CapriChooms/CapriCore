# Issue 79 — CPU voice setup cannot find the Capri reference

The attached 0.6.1 setup report stops at `voice-runtime` with **The Capri reference voice is missing. Repair with Capri Setup including its voice pack.** Qwen3-TTS was selected. Source copying, dependencies, speech recognition and the request classifier had completed; the failure happened before Qwen runtime/model installation. The report does not establish why that installation lost its reference pack, and does not show a Qwen download failure.

Qwen's CPU model still needs the verified Capri recording for its voice identity. The wizard correctly leaves the optional Chatterbox `voicePack` selection empty in Qwen mode. However, it did not pass its independently supplied `BundledVoicePack` to the worker. The engine found the seed only at `sourceRoot/.bundled-voice`. A Setup/repair invocation whose included pack lives elsewhere could therefore lose that source and produce the exact reported error.

## Change

The wizard now carries its included reference independently as `bundledVoicePack`, including when Qwen or text-only mode is selected. The worker and Node policy require a verified absolute, link-free path. Before dependency installation, the engine validates the pinned base-model metadata and the public `capri-en-v1` identity, then retains the seed in the owned installation cache. The existing source-relative seed remains supported.

This does not select Chatterbox, add its GPU requirement or install its dependencies for Qwen. Existing valid custom reference settings remain usable. If the supplied reference is missing or damaged, Setup fails before downloading/installing dependencies rather than inventing a replacement voice.

## Reproduction and verification

Use a source/repair invocation without `sourceRoot/.bundled-voice`, pass the included verified Capri pack separately, select Qwen and leave the optional Chatterbox pack empty. The isolated prior-engine regression fails with the exact missing-reference error. The corrected transaction imports the reference and reaches Qwen dependency/model preparation on the CPU-only fixture.

The regression uses disposable installation directories and synthetic voice files, and never runs voice models or records audio. A separate case checks early failure for a missing or relative included-reference path. Existing catalog-preparation cases cover preserving a valid custom reference and cancellation. Final test totals are recorded with the local 0.6.3 build; this document does not claim an end-to-end reproduction on the reporter's computer.
