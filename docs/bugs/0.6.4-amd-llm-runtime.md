# AMD local language-model runtime delivery

Some supported Windows Radeon cards received only Ollama's base archive during
Setup. The separately distributed ROCm backend was absent, so those cards could
use the included Vulkan backend but could not select their supported ROCm path.
This is separate from the GPU requirements of Chatterbox or other voice engines.

Setup now installs the SHA-pinned Ollama 0.40.10 ROCm add-on only for a local-model
installation with a GPU in Ollama's documented Windows ROCm matrix. API-only
installations and Radeon cards outside that matrix retain the base runtime and
Vulkan route. Capri does not spoof GPU targets, force an unsupported ROCm backend,
or select CPU merely because a card is AMD. Ollama still decides actual GPU
discovery and layer placement with the installed driver and available memory.

The extra download is 256,578,673 bytes and expands to 1,025,349,792 bytes; both are
included in the wizard's and worker's disk estimates. The add-on has its own
installation receipt. Repair verifies every installed backend file, including
kernel/data files, and restores missing or changed files from the pinned archive.
Replacement is prepared in a clean staging directory: stale files from an older
backend cannot become part of the new archive receipt. The previous backend is
retained as an owned backup, and a failed promotion restores it before returning
an error. Installation data and model weights are outside this replacement.
The base runtime check also verifies the Vulkan backend and its DLL dependencies.
Linked runtime files, linked archive destinations and linked partial-download
files are rejected before repair can overwrite or append to their content.

To verify the change, select local models on a supported Radeon system and check
that Setup downloads the ROCm add-on once. Repeat Setup with the same installation:
the complete verified backend is reused. Removing or changing an add-on kernel
file must cause repair, even when `ollama.exe` and `ggml-hip.dll` remain present.
Selecting API mode, or using a Radeon outside the Windows ROCm matrix, must not
add this download. Actual acceleration can be checked in Ollama's backend
inventory; an AMD driver warning alone does not prove that Vulkan failed.

Headless regression fixtures cover these selection, repair and estimate paths
without executing a GPU backend. No performance gain or qualification on untested
AMD hardware is claimed.

Primary references: [Ollama hardware support](https://docs.ollama.com/gpu),
[Windows distribution](https://docs.ollama.com/windows), and the
[pinned release](https://github.com/ollama/ollama/releases/tag/v0.40.10).
