# Донаты в Capri через Lava.top

## План внедрения

1. Добавить в «Поддержку» кнопку «Поддержать через Lava.top» и резервный переход в системный браузер. Оба действия используют официальную ссылку на донат автору Overyx. [Схема API](https://gate.lava.top/docs), [инструкция для авторов](https://faq.lava.top/article/68566).
2. Открывать форму оплаты как отдельное окно Capri. Для страницы Lava.top использовать песочницу Electron, собственную сессию в памяти и ограничения навигации. Оплата и ввод данных происходят на стороне Lava.top. Открытие окна или переход на страницу сами по себе подтверждают только начало сценария. [Инструкция для плательщиков](https://faq.lava.top/article/63036), [рекомендации Electron](https://www.electronjs.org/docs/latest/tutorial/security/).
3. Сохранить ссылку на профиль для действующих подписок. Если для оплаты требуется переход за пределы Lava.top или отдельная вкладка, предложить продолжить в системном браузере. После оплаты результат подтверждает Lava.top, а автор видит донаты в разделе продаж. [Документация Lava.top](https://developers.lava.top/ru), [где проверять донаты](https://faq.lava.top/article/68566).
4. Проверить открытие формы, повторное нажатие, сбой загрузки, резервную ссылку и изоляцию окна. При выпуске проверить тестовый платёж с согласованной суммой и сверить его в кабинете автора.

## Настройка у автора

В кабинете Lava.top достаточно включить «Донаты» на странице автора. `GET /api/v1/donate` возвращает публичный адрес формы. Для этого сценария используется сам адрес. Авторизация для просмотра формы и обработки денег выполняется Lava.top. [Настройка донатов](https://faq.lava.top/article/62998), [схема API](https://gate.lava.top/docs).

Webhook на скриншоте предназначен для уведомлений на сервер автора. Для добровольных донатов Lava.top показывает результат в форме и кабинете. Документированные `payment.success` и `payment.failed` применяются к покупкам и первому платежу по подписке. Серверный webhook имеет смысл при отдельной задаче по обработке таких событий. [События Lava.top](https://developers.lava.top/ru#webhook).
