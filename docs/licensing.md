# Redistribution and license checks

Capri's original application code is licensed **GPL-3.0-only**. The full license
text is in [LICENSE](../LICENSE) and must remain intact. Dependency notices and
asset terms are listed in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

When conveying a setup executable, provide its complete matching Corresponding
Source under GPLv3 section 6, including the build and installation scripts and
Capri's compatibility patches. Include the license and existing copyright and
attribution notices. Source access must not require a special unpacking password
or key. Merely linking an unrelated current branch does not establish that it
matches a distributed binary. The source export and setup's extraction mode
help package that source; verify the actual release artifact before distribution.
See the [GNU GPLv3 text](https://www.gnu.org/licenses/gpl.en.html) and
[GNU license FAQ](https://www.gnu.org/licenses/gpl-faq.html).

The npm SBOM is an inventory, not a legal compatibility conclusion. Keep the
upstream licenses/notices for redistributed runtimes and dependencies, and
review license compatibility when dependencies change. Optional Python
environments and downloaded model weights need their own inventory and terms.

The GPL code license does not grant character, artwork, recording, performance,
voice identity or trademark rights. The separate
[character asset notice](character-assets.md) describes this limitation; a fan
project disclaimer is not permission from a rights holder. Do not claim that
provenance hashes, a model's availability on Hugging Face, or an installer
manifest establish such permission. Verify the applicable permissions before
redistributing an optional voice/artwork pack or using it commercially.
