# Capri 0.6.2

Release notes and a manual verification guide for Capri 0.6.2. Building or extracting the installer does not modify existing installations or user data.

## Main changes

- The home reply bubble has a Hide reply button and a compact Show reply tab. Hiding preserves the response and audio playback; streaming and speech events do not reopen that manually hidden turn. Hidden subtitles pause pagination work and reflow once when shown again.
- Virtual microphone setup rechecks the connected physical input instead of borrowing a stale/default ASR track after hotplug. Disconnecting during setup is reported as an unavailable microphone before feedback-loop validation; a missing input cannot be marked as a live call mix.
- Voice Calls can automatically send a request after a wake phrase from the combined microphone/system input. Wake-disabled and manual-send modes remain drafts; background speech, Capri's own playback and obsolete sessions do not submit requests.
- A globe button beside Thinking enables Internet search in both input bars. It starts off, highlights while enabled and can be combined with deeper reasoning. Only the current request is sent to bounded, keyless web search; history, memory, attachments and screenshots are not automatically sent. Recognized credentials are blocked before searching. Replies can cite numbered sources, with clickable references in Conversation. Failed or empty searches preserve ordinary answers with an explicit freshness limitation.
- Computer tasks keep a bounded checklist of observable results and revise the remaining work when an ordinary dialog or a foreground change blocks progress. Opening a browser with multiple existing windows no longer stops at the window-selection prompt. Delivered navigation is not blindly repeated; completion still requires current evidence and an independent review. The first checklist shares the first action's model request.
- Saved API connections can be edited in place. Leaving the key field empty keeps its encrypted value; changing provider origin requires a new key. Applying an edited active connection uses the existing restart confirmation and preserves the previous selection on failure. Inactive edits do not switch providers.
- **Credits → Hall of Fame**, beside Support the author, honours Overyx, v1rch and Leberrr with God Rays, includes five major donors and five community helpers with saved callsigns, and lists 608 early-access GitHub nicknames. Nicknames have animated gradients; lighter glow and bounded motion work reduce scrolling overhead. All effects pause during scrolling and resume without resetting their position. The theme-aware panel has local search, with all new text translated into 50 interface languages. Its roster is bundled offline; manual refresh preserves existing acknowledgements. See [maintainer notes](../hall-of-fame.md).
- A compact out-of-frame panel with Microphone, Keyboard and Menu. The keyboard opens the text composer; Menu expands the full panel. An optional green dialogue-only presentation hides the character. Completed replies can hide automatically after playback and a configurable delay, while history remains available.
- Application access and screen observation can be toggled from the toolbar. A small restore chip remains after ordinary minimization; Focus mode stays entirely hidden. Installed applications can be found by name and granted launch permission without browsing for an executable.
- **Brain and private memory** adds an offline document folder and local search over TXT/Markdown, DOCX/ODT and text PDFs. Relevant excerpts reach an external API only after explicit permission. Private notes and private conversations use a separate password-encrypted store and bypass ordinary history and tools.
- The existing memory viewer now has a direct **Add memory** form with a verified save receipt.
- **Task training** records clicks, dragging, scrolling and shortcuts into editable workflows. Text is added manually or through variables. Recording has an independent stop indicator; playback uses current computer permissions, fresh target checks and Esc cancellation.
- **User tools** discovers reviewed Node, Python and executable extensions, with JSON parameters, encrypted settings, time limits and Windows isolation. Tools can be called by a compatible model or contribute bounded, keyword-triggered reference context. See [the tool format](../user-tools.md).

## Where to check

Open **Credits**, verify the three team roles, five major supporters and five community helpers, search for a GitHub nickname and clear the query. Check the animated name gradients and the team God Rays, then scroll: effects should pause and resume without jumping. Switch themes and try a narrow Settings window. The list should display without a token or Internet connection, and typing into its search must not create unsaved settings changes.

1. Leave the home frame. Check the three compact icons, expand/collapse text entry, attach a file and return to the full panel. Draft text and attachments should survive these changes.
2. In **Appearance and animations**, try the detached dialogue presentation and reply auto-hide options. A spoken reply should remain visible until playback ends, then hide after the delay. Hovering, selecting text or viewing history should keep it visible.
3. Pause application access from the toolbar. Existing grants should remain listed, but actions must stop. Re-enable access and search for an installed application by name; granting launch must not grant typing or window inspection automatically.
4. Minimize Capri and restore her using the chip. Enable Focus mode and confirm that neither the character nor the chip interrupts the screen.
5. In **Brain and private memory**, open the Brain folder, add a small recipe document, refresh and search for one distinctive ingredient. Change/delete the file and refresh; stale excerpts should disappear. API sharing is off by default.
6. Create private memory with a test password, save a note and lock it. A wrong password must not reveal it. Reopen Settings, unlock it and check the note. Test changing the password and confirm that the previous password no longer works. Private replies must not appear in ordinary Conversation history.
7. In **Conversation and personality → Memory**, add a fact, check the save receipt and reopen the viewer to confirm persistence.
8. In **Task training**, record a short sequence in a disposable application, stop with the independent indicator or Esc, review the steps and add a text variable. Enable full computer access only when replaying. Try a changed or ambiguous target: playback should stop rather than click an arbitrary location.
9. In **User tools**, create the disabled example, inspect its permissions, enable it and run a test. Change its code and refresh: approval should be invalidated. Try cancellation and an invalid manifest. Private settings should show an encrypted-state placeholder rather than their saved values.

## Verification and practical limits

Perched-avatar interaction after minimizing and restoring Discord remains unresolved in the live Z retest. A separate native/content visibility regression has a local repair, but it did not eliminate the reported user failure; do not list the overall issue as fixed.

Earlier development checks used isolated profiles, synthetic documents and owned test windows. They covered Windows recording, semantic click/type/shortcut/copy/paste/drag playback, visible UI controls, encryption, file and network restrictions, cancellation, localization and installer extraction. They do not constitute a full regression run of the final release. At the maintainer's request, final tests and hardware checks were deferred, including the latest microphone-hotplug, reply-collapse and Credits changes. Packaging still validates the source boundary, credentials, public defaults, installer catalogue and checksums. Installer hashes accompany the download.

Brain uses a background worker and SQLite full-text search, without an additional model or GPU. Scanned PDFs need text recognition before importing. A maximum of 200 bounded documents is indexed. Searching a document is retrieval, not model training.

Workflows require accessible, uniquely identifiable controls. They cannot guarantee replay in every game or application. Ordinary typing, passwords and clipboard contents are not recorded; fill text steps during review. Workflows are saved procedures, not changes to model weights.

Windows may refuse the temporary network-block policy required for an offline user tool, depending on account privileges and system policy. In that case the tool does not start. Capri never silently runs it outside isolation. Network-enabled extensions must be trusted with their explicitly supplied inputs and private settings.

Private memory protects its encrypted files while locked. It does not retroactively encrypt ordinary chat history, protect against a compromised administrator, or keep data private from an external provider when the user explicitly permits that private request. Forgotten passwords cannot be recovered.

New public UI text is included in all 50 supported interface languages. Machine-translated additions still benefit from native-speaker review.

Backend measurements are documented in [the performance report](../performance/0.6.2.md). These results describe two CPU functions, not model generation speed or overall application performance.
