# Capri 0.6.3

Hotfix release. The installer and source archive include the changes below.

## Main changes

- Fixed web-answer recovery after context compaction: the current question and retrieved references remain available, and reserved avatar/private-channel markers are filtered before display and speech. Ordinary Internet requests cannot implicitly start computer control, even with an existing full-access grant. Explicit current computer requests remain supported. See [reproduction and checks](../bugs/0.6.3-web-recovery.md).
- Fixed an installer path that lost the included Capri reference when Qwen TTS was selected. The reference now travels independently of Chatterbox selection; existing valid custom references are preserved. See [issue 79](../bugs/0.6.3-issue79.md).
- Refined VAC feedback-loop checks: a shared browser device group can be accepted only after freshly verifying a distinct physical microphone and an unambiguous VB-CABLE pair. Unknown or ambiguous routes remain blocked. Setup diagnostics retain only a stage and failure code, without device identities.
- Reduced retained Chatterbox reference memory by disabling autograd during reference preparation and releasing reference-only encoders. Native acoustic weights, precision and voice identity remain unchanged. A controlled CPU comparison produced identical PCM and lower process memory; see [the measured results and limits](../performance/tts-memory-local.md).
- Added hover lighting and left-button dragging to the restore chip. Dragging preserves its size and session position, stays within the monitor work area and does not trigger restore. Ordinary clicks and keyboard activation still restore Capri.
- Collapsed home replies use a toolbar button. Collapsing moves the upper controls down while preserving the portrait's size and position; opening history restores the normal page layout.
- Team God Rays follow the letters with animated highlights. The Credits page prevents horizontal overflow while retaining the internal glow. All new renderer imports are included in the served resource inventory.

## Verification

Final counts, artifact checksums and the precise verification scope accompany the installer. Verification uses disposable profiles, local API fixtures, synthetic documents/audio and owned test applications. The original external user's computer and a live call with a physical microphone are separate checks.

## Known limitations

- Interaction with Capri after minimizing and restoring Discord remains unresolved in the earlier user retest. Passing isolated stacking fixtures do not establish that the complete reported issue is fixed.
- npm audit reports two existing moderate-severity root advisories, [glob](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4) and [minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249), propagated into 33 package findings. No high or critical findings were reported. The bundled npm dependencies cannot be replaced by ordinary overrides; this release does not claim to resolve these advisories or downgrade OpenClaw.
- CPU TTS memory measurements are one controlled pair, not a guarantee for every language or GPU. Chatterbox's production GPU requirement and decoder placement policy remain unchanged.
- The Windows installer is unsigned.
