# Capri 1.0.0 — local beta test build

Prepared for beta testers. This build has not been published to GitHub.

## Changes to verify

- The red/green CapriCore lightning replaces the old face in Windows app, setup and uninstall icons, shortcuts, tray, window icons, notifications and the floating restore chip. Character sprites and animations retain their artwork.
- The Support page and README link to capri-core.com.
- Hall of Fame includes every current private-repository collaborator as of 2026-11-08: 670 current logins plus one retained historical credit, for 671 supporter names. The three team credits, curated donor/helper groups and existing callsigns are preserved. Nicknames are packaged locally; opening Credits does not contact GitHub.
- Capri's companion windows stay out of the Windows taskbar, including after hiding and restoring them. Use the existing system tray icon to reopen Capri.
- Collapsing the home reply also removes the backdrop from its empty reserved area; reopening restores the full backdrop without resizing Capri's native window.
- Full conversation encryption and its EFS/virtual-filesystem startup requirements are deferred. API keys retain their existing secure storage. Previously encrypted test history remains readable with its original key; unreadable files are preserved.
- AMD GPU monitoring retains available capacity when usage counters are unknown. The active local model reports CPU, GPU or mixed placement when measured. Supported AMD configurations receive the pinned ROCm backend; other Radeon cards retain the Vulkan route.
- Installer logs retain complete UTF-8 output and unfinished lines. Storage estimates include the selected GPU runtime.
- Electron downloads can use a pinned npmmirror fallback after a transient primary-host failure. Version, size and SHA-256 verification remain mandatory. See [network checks](../bugs/1.0.0-electron-download-mirror.md).
- Uninstalling keeps a responsive progress window open through preparation, stopping Capri, removing the selected components and final cleanup. It reports actual processed items and leaves the result visible until closed. The launcher can use a verified installed copy if its recovery files are missing.
- Explorer inspection, calculator requests, Spotify search after restoring its window, workflow editing and local computer-action planning include the latest fixes.
- Discord can address the already visible current, left or right chat pane, including a voice channel's text sidebar. An exact owner-requested message can be submitted once without inventing a server/channel name. Ambiguous panes, unrelated drafts and uncertain submissions stop safely. See [the report and verification limits](../bugs/1.0.0-discord-current-chat.md).
- Settings translations, Windows window layering, local reply token budgets and diagnostic privacy have been improved.

## Suggested beta checks

1. Install into an empty folder, including a path containing spaces or non-Latin characters. Check the version, model selection and progress messages.
2. Restart with an external API selected. Check that the chosen connection persists and the local language model does not load unnecessarily.
3. On AMD, confirm the detected adapter and model placement. Unknown counters must show an unavailable reading, rather than an invented zero.
4. Try calculator expressions, Explorer inspection, Spotify search and a short multi-step computer-control task. Escape must stop computer control.
5. Restore a window with Capri sitting on it, then try headpat and dragging. This previously reported issue still needs testing on affected installations.
6. Check microphone startup, speech playback, saved conversation attachments and the translated Settings tabs.
7. Hide or close the main panel, reopen Capri from the system tray, and repeat. The taskbar must not retain a companion-window button.
8. When testing uninstall, check that progress remains visible after confirming the selected components. Unchecked models and personal data must remain intact. Completion must appear only after cleanup finishes.
9. In a Discord test channel you control, open its text sidebar and request a specific short message in the chat on the right. Check that Capri uses that pane, submits once and leaves another pane's draft untouched. A locally submitted message is not a guarantee of server delivery.

The installer is unsigned. This is a beta, not a claim of qualification on every GPU or audio device. The native English recognition crash reported in issue #80 remains unconfirmed. No call audio is sent automatically by these preparation checks. See [security limitations](../../SECURITY.md).
