# Capri 1.0.0

The first public release is available from [CapriChooms/CapriCore](https://github.com/CapriChooms/CapriCore/releases/tag/v1.0.0).

- Local language models, Hugging Face GGUF selection and OpenAI-compatible APIs, with optional local voice and 50 interface languages.
- A desktop companion with floating dialogue, animated reactions, music listening, configurable effects and resource monitoring.
- Explicitly enabled computer tools, app/file access, Discord and Spotify actions, workflows and user tools.
- Public downloads, update checks and voice-pack recovery without a GitHub account or token. Optional saved access remains encrypted.
- Installer, AMD runtime/monitoring, application-control and privacy fixes accumulated during early access.
- Hall of Fame: all 670 current early-access collaborators plus one retained historical credit, with the core team, donors and community helpers preserved.

## Install or upgrade

Download **CapriSetup-1.0.0.exe**. For an existing installation, select its current folder without uninstalling; keep its data and models. Older private-channel versions need this one-time manual installation to switch to public updates. A new installation can use an external API without downloading a local conversation model.

The exact matching GPL-3.0-only source archive, voice-pack recovery archive, build manifest and SHA-256 checksums accompany the installer. See [licensing and asset terms](../licensing.md).

## Limits to know

The installer is unsigned. Computer control and some model/voice adapters remain beta features; Escape stops an active control session. GPU acceleration depends on the adapter, drivers and runtime. The earlier report about interaction after restoring a window with Capri sitting on it still needs confirmation on affected installations.

Conversation history and ordinary memory are stored locally and are not fully encrypted. API credentials and the separately password-protected private memory retain their existing protection. Cloud providers receive the content needed for requests when selected; review diagnostic reports before sharing them. See [Security](../../SECURITY.md).
