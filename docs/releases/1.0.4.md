# Capri 1.0.4

- Fixed ordinary conversation timing out before the model received a request. An intentionally empty dialogue tool list is now accepted; invalid plugin allowlists still fail closed. Personal-memory access and tools for later action requests remain available in their own modes.
- Generic music and artist requests use an isolated, validated Spotify plan instead of the general chat/tool history. Playback is acknowledged only after verification in the player.
- Malformed generated tool calls and stray failure punctuation are kept out of subtitles and speech.
- Expanded gateway integration checks cover dialogue with zero tools, personal-memory mode, calculator, Spotify, computer actions, and restoration of tool access after dialogue.

Run **CapriSetup-1.0.4.exe** and choose the existing Capri folder to preserve models, conversations and settings.
