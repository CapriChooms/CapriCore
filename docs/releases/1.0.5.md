# Capri 1.0.5

- Reserve resources with the checkbox and slider in **Local**: CPU quota and an adaptive GPU target, enabled at **85%** by default. Changes apply during replies and persist across launches.
- Corrected installer RAM/VRAM estimates using the optimized model footprints and automatic voice-decoder placement; a small VRAM shortage no longer counts as a full extra CPU model.
- Updating through Setup now keeps the actual selected local model by default, marks downloaded models, includes existing Hugging Face imports, and lets you select and download a different model.
- Setup now sends a Windows notification when installation finishes successfully, highlights its taskbar icon in the background, and opens the finish page when the notification is clicked.
- Fixed recovery after competing GPU work ends, temporary load spikes caused by lowering the slider, stale GPU associations when model runners change, and missing control during proactive local replies. Quotas are released on idle, API mode, disable and shutdown; helper failures are recovered without stopping the model.
- Added optional external TTS with encrypted credentials, connection testing and local voice unloading. Local voice remains the default; enabling cloud voice sends reply text to the selected provider.
- Added installed AI app discovery and an official ChatGPT plan connection where supported, optional desktop roaming with adjustable frequency, and model/device/API shortcuts on RAM/VRAM warnings.
- Simplified ChatGPT setup: automatic account-specific model lists, one-step **Use connection**, visible loading/retry states, and recovery when Windows leaves browser launch pending after successful sign-in.
- Fixed ChatGPT model discovery rejecting larger catalogs as “response exceeds its limit” and silently dropping choices beyond the first 100 models.
- Fixed ChatGPT connection tests and replies rejecting valid SSE streams when the direct route omits Content-Type; network failures also retain the correct error classification.
- Fixed startup being blocked by an update receipt left behind after a successful update or completed rollback. Incomplete updates still require recovery or Setup repair.
- Fixed Qwen3-TTS installation failing Python verification because its restricted Windows environment omitted executable extensions; voice installation failures now retain a private technical cause and stage in diagnostics.
- Fixed ChatGPT connections marking Terra as text-only. Model capability discovery now uses bounded catalog metadata and reviewed exact IDs, repairs the old default, and preserves manual vision overrides. Normal Terra replies and intent classification explicitly disable reasoning; deep thinking remains opt-in.
- Diagnostic log limits now retain the latest events, including the final timeout, rather than discarding them after the first 500 records.
- Thinking mode is silent by default: no separate introductory reply is generated or spoken before the final answer, including requests with images.
- Simplified Voice API setup into provider/key, voice, and connection steps, with one **Save and test** action, visible encrypted-key state and an explicit cloud-voice switch. Missing keys and invalid settings are explained inline instead of misleading network errors.
- Fixed music requests such as **“play something cool”** failing before Spotify when using a ChatGPT connection. Planner schemas are now adapted to Responses without weakening action validation; planning failures retain a safe code and HTTP status.
- Updated all 50 interface languages and expanded real CPU/GPU, native recovery and interface checks.

Run **CapriSetup-1.0.5.exe** and choose the existing Capri folder to keep models,
conversations and settings. The installer includes the reviewed Capri English
voice profile; base models and optional dependencies download separately.

GPU control targets average utilization rather than a hard instantaneous ceiling.
It does not limit VRAM or local TTS. Lower limits make replies slower. See the
[load control guide](../local-model-load.md) and [qualification notes](../verification/1.0.5.md).
