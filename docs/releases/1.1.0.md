# Capri 1.1.0

Changes since [Capri 1.0.4](https://github.com/CapriChooms/CapriCore/releases/tag/v1.0.4), including the 1.1.0 experimental builds.

## CapriCore and Skills

- Settings now separates CapriCore from Skills. Each skill has its own icon, description, enable switch, settings and optional toolbar shortcut. Settings remain accessible when a skill is disabled. Voice input and spoken replies have shortcuts by default. Attachments are enabled by default and appear in the input bar. Attachments, Deep thinking and Web search support separate toolbar and input-bar placements.
- The toolbar grows with the number of visible shortcuts. The Settings sidebar can be resized to fit longer translated skill names. Updated the desktop and installer translations across the supported interface languages.
- CapriCore coordinates requests through a shared skill interface. A request uses only the prompt instructions, context and tools relevant to its enabled skills. For example, a disabled Spotify skill contributes no playback state. Casual dialogue uses less system context, and provider and tool errors are kept out of replies.
- The developer view shows more request stages and clearer failures without including prompt or conversation contents. Graphify support gives contributors a source dependency graph and named communities.

## Language models and API connections

- Local language models now use llama.cpp with CPU or Vulkan, while OpenClaw continues to coordinate the conversation gateway. Setup reuses compatible Ollama cache files and retrieves compatible weights and vision projectors when needed. Hugging Face GGUF imports are checked against the local runtime before selection. Incompatible or missing weights and failed device loads get distinct errors.
- The **Local** menu offers live resource controls with an 85% default target. CPU quotas and adaptive GPU utilization help leave resources available for other apps. GPU targets apply to average utilization. The language model and voice model have separate device settings. RAM and VRAM warnings offer shortcuts to switch the model, switch the device or use an API.
- Added experimental native NPU inference with guided device selection and a test generation before applying the device. AMD and Intel support depends on compatible hardware, Windows and vendor runtimes. Advanced setup supports manually configured compatible models and runtimes, including Qualcomm QNN.
- Capri can discover installed AI apps and local servers. Supported ChatGPT accounts can authorize a separate connection, load their available model list, test it and select a model. Fixed stalled sign-in, oversized model catalogs, valid streams with missing headers, and incorrect image and reasoning detection for supported Terra models.
- Deep thinking is silent by default, with configurable effort on supported models. Fixed ordinary requests getting routed into reasoning, replies timing out during model preparation, and excess attachment or history context consuming the reply budget. Oversized text-only API requests get a bounded retry with a shorter history where supported. Image and tool errors have more specific messages.

## Voice, music and avatar

- **Spoken replies** separates Local and Voice API options. Optional cloud TTS supports OpenAI-compatible providers and ElevenLabs with encrypted credentials and a connection test. Local voice remains the default. Cloud TTS sends reply text to the selected provider and allows the local voice model to unload.
- Added the experimental Russian Capri Qwen3-TTS 1.7B LoRA voice with a Russian stress model and optional NVIDIA CUDA or supported AMD ROCm acceleration. The voice picker and installer show the compatible options and prerequisites. CPU synthesis remains available and can be slower than real time. Voice model preparation and download errors now identify the failing stage more clearly.
- Voice input adds microphone monitoring, an input level meter and 0–200% gain. Open the speaker menu to adjust Capri’s volume. Zero volume stops spoken replies and unloads the local voice model. Voice preparation and cancellation are coordinated with text replies so text can remain available when speech fails.
- Music reactions wait for a usable BPM when automatic matching is enabled. Tempo detection handles quieter passages and retains a usable tempo during short gaps in detection. Updated music poses and note timing.
- Capri can roam the desktop at an optional, configurable interval. Updated pose assets, including the sleeping pose for connecting and disconnected states. Removed the retired poses and restored the 1.0.4 eye artwork on the current poses. Headpats keep the current pose and add facial reactions and hearts. Music animations continue with hearts only. Spoken click reactions follow the conversation language. When a window Capri is perched on is minimized or closed, she detaches and relocates. Improved teleport placement across displays and at mixed DPI.
- Optional auto-hide dismisses the detached reply bubble after speech ends or after a delay for text-only replies. Conversation supports selectable text, per-message copying and clearing the history. Capri’s personality and the Neutral, Romantic, Business and Wild styles have been revised. Added a local Cyberpunk lore reference and character cues for image questions when the model supports vision.

## Desktop, search and productivity

- Computer control shows a centered, animated sequence of checkpoints and advances after verifying results. It observes the active display, including the taskbar, refreshes across window changes and checks visual targets against the latest screen and accessibility information. Escape still stops the session. The overlay fits the work area and step cards retain their angled outlines.
- Improved recovery from stale targets, numeric model-generated checkpoint IDs, repeated actions and incorrect completion claims. Local app and installed Steam game requests can use verified app or game discovery. A completed launch step keeps the rest of a multi-step task pending. Improved the Spotify playback and connection paths, including ChatGPT tool schemas.
- Screen Observation uses changes in the screen or foreground app to decide when to capture again. Higher-detail captures help with small text. Image and file support is shown for the active model, including supported attachment formats and vision requirements.
- Coding mode accesses an approved project folder through editor adapters. Supports the VS Code family and an optional live-document bridge, plus JetBrains IDEs, Visual Studio, Sublime Text, Notepad++, Neovim and Emacs client. Project file actions and approved build/test commands work without full desktop control.
- Web search adds engine selection, site filters, source presets and ordering options. Initiative supports up to 120 opportunities per hour. Task Training records mouse trajectories and can replay them with the existing user and window checks. User Tools can be edited, disabled or removed.
- Saved memories show short facts, with manual addition, editing and deletion. The timer’s hours, minutes and seconds scroll independently with inertia. The Calculator skill can show a supported expression and its result in Windows Calculator when enabled.

## Setup, updates and support

- Setup retains the selected local model by default during upgrades, lists already downloaded and imported models alongside other choices, and lets you choose a new model and conversation language. Download estimates account for files and components already available. A prominent disk-space warning explains why installation cannot start. Dropdowns stay with their controls while scrolling, and the wheel no longer changes a closed model selector.
- Active downloads show the file name, percentage and downloaded bytes versus file size. A sleeping Capri sprite follows the overall progress bar. Node.js has a verified fallback mirror. Large CUDA voice packages use resumable, hash-verified downloads with bounded retries and no 15-minute transfer cutoff. Setup notifies you on completion and recovers from stale update receipts after successful updates or rollbacks.
- The Windows x64 installer allows Windows 10 1809 through 21H2 experimentally and recommends 22H2 or Windows 11. GPU/NPU drivers and optional speech runtimes have their own requirements. Improved per-user installation and localized uninstall, including progress, diagnostics and recovery for a missing uninstall bundle. Electron is pinned to 45.3.1.
- Settings shows release history and changelogs. Stable releases come from CapriCore. Experimental releases require opt-in and GitHub access to the private Capri repository. The support panel includes Boosty, Lava.top and Capri community links. Bug reports can be saved as a local ZIP or explicitly sent to the Capri report server.

## Updating from 1.0.4

Close Capri, run `CapriSetup-1.1.0.exe` and select your existing installation folder to keep your settings, conversations and compatible local models. Setup may download updated runtimes, compatible model files and the optional voice dependencies you select. Use the full installer if the old in-app updater cannot complete the upgrade. The Russian LoRA voice, native NPU and older Windows support are experimental.
