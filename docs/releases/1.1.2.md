# Capri 1.1.2

- Added Brazilian Portuguese for the application, Windows Setup, updates, uninstaller, and conversation. Choose **Português (Brasil)** in **Settings → Languages**. Local speech recognition uses Parakeet V3, and the default spoken voice uses the dedicated Chatterbox Brazilian Portuguese model. Qwen3-TTS also supports Portuguese.
- Fixed a Windows microphone startup failure after updating Capri. The speech worker loads the ONNX Runtime shipped with its pinned Sherpa-ONNX environment.
- Fixed a message submission failure when the composer still showed thinking or web search as enabled after the corresponding skill had been turned off. Known reasons for rejected messages now appear in the interface and in response timing diagnostics.
- Improved routing for simple factual questions when action skills are disabled. Capri can answer those directly without preparing actions.
- Added a checksum-verified mirror for the pinned llama.cpp download. When the Vulkan startup attempt stalls in Automatic mode, Capri leaves time to try the CPU instead.
- Improved diagnostics for local model startup and message submission failures.

Run **CapriSetup-1.1.2.exe** and select your existing Capri folder to keep your settings, history, and compatible models. The Windows installer is unsigned. The release includes SHA-256 checksums.
