# Capri 1.2.0

## Interface and guides

- Added an optional horizontal layout, live layout previews and edge resizing in both layouts. The reply bubble now opens and closes smoothly. The window follows it in the vertical layout and keeps its lower edge in place.
- Added a beginner walkthrough, an FAQ and interactive guides throughout Settings. Use **?** to open a guide and **ⓘ** beside a setting to jump to its explanation. Settings are grouped by feature and follow the active theme.
- Expanded resource monitoring. Select up to four graphs, set a refresh interval of 1–10 seconds, and choose where the monitor appears in the horizontal layout. Longer charts show more history at the same scale.
- Added the Sandevistan teleport effect with adjustable afterimages alongside Lightning. Capri also has new community-contributed animations, smoother zoom and a reset that fits the full sprite.

## Audio, music and voice calls

- Added a dedicated **Audio** tab for microphone input, spoken reply output and music capture. It supports virtual audio routes used with VoiceMeeter, Voicemod and similar tools.
- Added YouTube Music support for search, playback and player volume. Capri prefers an existing YouTube Music tab and can handle the inactivity prompt when you request playback.
- Added **Capri Camera (BETA)** for Windows voice calls, with a live preview and adjustable background. Select **Capri Camera** as the video device in an app that supports it.

## Skills and reliability

- Improved Chess board selection, edge detection and recovery after the board moves or disappears. The overlay passes mouse clicks through. It has configurable arrows, frame effects and shorter reactions based on confirmed moves and Stockfish analysis.
- Expanded Coding mode with project file watching, editor integration, file creation and editing, reviewable changes, and approved build and test tasks.
- Improved Computer control routing, full-monitor capture and verification of requested actions. Named Steam games use the installed library when available. Capri reports when it cannot confirm that an action succeeded.
- Improved response recovery, microphone startup and explicit requests to save facts to Conversation memory.

## Installation and updates

- Reworked Windows Setup into a guided questionnaire with hardware and memory estimates for local model choices. Updated the progress display and retry diagnostics.
- The update window and uninstaller now match Setup. While files are being removed, you can minimize the window, pause, resume or cancel after the current operation. You can run the uninstaller again to remove the remaining files.
- Added automatic update checks in **Settings → Updates**. The option is enabled by default, so Capri can notify you while it is running.

To install, download and run **CapriSetup-1.2.0.exe**.

To update from 1.1.2 or an experimental build, use the in-app updater. You can also close Capri and run Setup against your existing Capri folder to keep your settings, history and compatible models. The Windows installer is unsigned. SHA-256 checksums are included with the release.
