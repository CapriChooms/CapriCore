# Capri 1.2.1

- Improved the smoothness of opening and closing the reply bubble and dragging the Capri window. While the window moves, it updates up to 60 times per second.
- Fixed a Windows issue that could leave an open Settings window hidden. Capri restores the window and keeps unsaved changes.
- Fixed GPU selection for Breeze TTS 2. The voice settings now list Vulkan devices detected by Breeze, including supported AMD Radeon GPUs, and apply the selected device to speech generation.
- Improved recovery after an in-app update fails. Rollback skips unchanged Windows launchers, restores the previous dependencies if reinstalling them fails, and records the failing stage for troubleshooting.

To install, download and run **CapriSetup-1.2.1.exe**. If an earlier update left Capri unable to start, close Capri and run Setup against your existing installation folder to repair it while keeping your settings, history and compatible models.

The Windows installer is unsigned. SHA-256 checksums are included with the release.
