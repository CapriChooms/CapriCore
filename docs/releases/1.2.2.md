# Capri 1.2.2

- Kept the desktop toolbar to two rows. The version, model selector and context indicator share a row with controls. Long model names can scroll within the selector.
- Added voice output gain up to 200% in Audio settings and the voice volume menu. The gain applies to playback on the selected output device.
- Made avatar animations easier to trigger in conversation. Capri can do pull-ups, play seated animations and pick a pose-appropriate animation while idle.
- Added a fallback that keeps Capri's portrait visible after WebGL or GPU renderer failures.
- Added crash reporting that opens the logs folder and lets you save and review a diagnostic ZIP to send to Overyx. Capri also records more detail about voice startup, wake-word capture and stalled tool calls.
- Improved reliability for simple conversations with local models and gave large contexts and CPU inference more time to produce text. API failures now identify missing endpoints or models and provider rate limits.

Download and run **CapriSetup-1.2.2.exe** to install. If Capri already runs on your PC, use **Settings → Updates** to update.

The Windows installer is unsigned. SHA-256 checksums are included with the release.
