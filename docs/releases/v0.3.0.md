# Capri v0.3.0

Numbered releases replace Preview names. Future releases use v0.3.1, v0.3.2 and later
semantic versions; existing Preview installations can update to v0.3.0. Repository,
support and update links now use CapriChooms/Capri.

- Removed the duplicate, inactive menu button from the second toolbar row.
- OBS is always available as a toggle. First use opens source selection; subsequent
  clicks stop or restart the selected source. OBS, REC and CLIP labels fit the standard button size.
- Ordinary text and microphone requests with screen observation enabled now request
  a fresh selected-source frame and analyse it before sending conversational context.
  Background throttling no longer substitutes an older description. Failed or revoked
  capture cannot silently reuse an old frame. Images remain local and transient.
- Multilingual speech now checks its optional model files before startup. Languages
  shows missing models and provides a setup button. Applying languages again after
  setup retries the voice. Missing/corrupt model errors retain actionable diagnostics.
  Parakeet provides recognition; multilingual voice output additionally requires
  Chatterbox Multilingual weights. English retains the trained English voice.
- Error notices include a Report a bug shortcut to the existing diagnostic report form.
- The bundled default screenshot cue uses the supplied Steam screenshot sound.
  Existing custom `data/sounds/screenshot.mp3` files still take precedence.
- Direct sleep commands such as “Capri, you can sleep”, “Capri, it's time to sleep”
  and “Капри, иди спать” work locally without a language-model request. Capri closes
  her eyes and shows Zzz with a 500 ms caption step. Capital letters advance low-bit
  first and each pattern cycles through one, two and three dots.
- Sleep stops Capri's owned language/embedding/voice model services and the CPU request
  router. Screen observation is revoked. An already enabled CPU speech recognizer is
  retained so an explicitly addressed voice request can wake Capri; an inactive recognizer
  is released. A typed request always wakes her. Wake reloads the configured services
  with progress feedback and then submits the original request. It does not change voice,
  language, model or microphone preferences or automatically re-enable screen capture.
- Increased the bounded hit-region capacity to accommodate the complete toolbar and
  error controls, fixing rejected click-region updates.

The Windows installer remains unsigned. GPU voice support and multilingual model
requirements remain as described in the installation guide.
