# Capri v0.3.1 — Windows installation hotfix

Fixed installation failing with `Get-Item: AppData not found` during speech
recognition, voice or CPU classifier setup. Windows hides the AppData folder;
the Python bootstrap checked ancestor paths without including hidden items.

The bootstrap now reads hidden ancestor attributes correctly without changing
folder attributes, permissions or the existing rejection of filesystem links.
A regression reproduces installation under a hidden AppData directory and verifies
Unicode paths, interpreter reuse, version checks and junction rejection.

If v0.3.0 setup failed with this error, download **CapriSetup-0.3.1.exe**, run it and
select the same Capri installation folder. Existing data and downloaded files are
preserved; verified components can be reused. Retrying the old v0.3.0 installer
alone does not include this fix. The English Capri voice remains included.
