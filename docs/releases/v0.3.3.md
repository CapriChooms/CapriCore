# Capri v0.3.3

Pre-alpha maintenance release. Install with **CapriSetup-0.3.3.exe** and select your
existing Capri folder to update/repair it. Personal conversation, memory, settings
and downloaded models are retained. The setup includes the reviewed sprite pack
and the trained English voice pack; optional runtime/model downloads still require
internet access and sufficient memory/disk space.

## Setup diagnostics in one click

- **Save report (ZIP)** is available during installation and after a failed setup.
  It saves an archive to Downloads and shows the file in Explorer. If Downloads is
  unavailable, setup falls back to its local reports directory.
- Collection works through Windows/.NET even before Node, npm or Python is ready.
  Startup UI failures also offer diagnostic export. An extracted source installation
  includes **Save setup report.cmd** for a broken or closed setup interface.
- Reports include installer/session and recent npm/UI log tails, selected setup
  options, exact version and CPU/RAM/GPU/driver information where available. Missing,
  locked or malformed records do not prevent a partial report.
- Credentials and personal paths receive best-effort redaction. Conversation,
  memory, personality, model weights and recordings are excluded. Nothing is
  uploaded automatically; review the ZIP before attaching it to an issue.

## Dependency download recovery

- Interrupted npm downloads now have a resumable recovery path for tarballs pinned
  by SHA-512 in the existing package lock. Verified content is added to npm's cache
  before retrying the same dependency installation. Partial bytes survive a short
  connection reset instead of always starting a large package from zero.
- The original npm registry, package versions, integrity pins and TLS checks are
  retained. No third-party mirror, cache purge or automatic dependency upgrade is
  introduced. Permission, authentication and integrity failures stop normally.
- A complete 103 MB OpenClaw package was downloaded from the official registry and
  matched against this release's lock. This confirms availability from the test
  connection; it does not establish the source of another user's ECONNRESET.
- Voice dependency setup retries recognized transient Git/package transfers with
  bounded backoff. After a Git interruption it tries process-scoped HTTP/1.1 without
  modifying global Git configuration. Exact Chatterbox/Perth and CUDA pins remain.
- The optional anonymous-download HF_TOKEN hint is replaced with a clear message
  that public voice weights do not require an account/token. Real authentication,
  rate-limit, integrity and download errors remain visible.

## Installation and source fixes

- The setup window has its own Capri taskbar identity and uses the Capri icon,
  instead of being grouped under the PowerShell host. The executable retains the
  complete application icon at every supplied size.
- Pause/resume reserves stable button and status space across installer languages,
  keeping the download log and footer in place when the status changes.
- The Support the author heart is centered vertically in its animated orbit.
- Repair can replace a read-only managed source file, retaining its old backup.
  Replacement is staged and uses bounded retries for short Windows sharing locks.
  Persistent access failures preserve old content and report the affected path.
- Standard GitHub source archives now retain all 68 reviewed Capri PNG frames and
  the runtime catalog. A stale export-ignore rule previously removed them from
  Code > Download ZIP. Private data/cache distribution exclusions remain.
- An incomplete installer source now directs the user to obtain a complete source
  archive or release setup, rather than repeatedly repairing from missing artwork.

## Conversation, voice and memory

- If a managed local Qwen model produces an invalid conversation summary, audited,
  bounded excerpts from the original history can recover compaction. The native
  context/quality checks remain. No session reset or automatic tool replay occurs;
  full transcripts and long-term memory remain stored, although older details may
  be absent from the active excerpt.
- Unavailable spoken languages offer an explicit install/text-only choice. Missing
  recognition models are identified separately. Portuguese and other non-English
  voices still require their optional multilingual model pack.
- Late audio packets after stopping/changing a microphone session are discarded
  without a spurious recognizer error or interference with the next capture.
- On PCs with up to 17 GiB RAM, muting speech releases the owned TTS worker instead
  of keeping GPU/RAM occupied. A quick unmute/preview is handled safely; re-enabling
  released speech can require a cold start. Larger PCs keep warm-mute behavior.
- Before a conversation query, Capri checks the selected Qwen context is resident.
  An expired/cold model is primed separately from the first-answer deadline. Fresh
  screen context follows loading. Cancellation/failure does not replay the query.
- Diagnostic snapshots distinguish model loading, response generation and TTS
  release state. These changes address observed state/resource defects; a physical
  retest is still required for the reported GTX 1660 Super/16 GiB timeout case.

## Validation

Coverage includes real Windows diagnostic ZIP export without Node, malformed and
linked log sources, redaction and fallback saving; a real npm install after a
mid-transfer reset with HTTP Range/SHA-512 recovery and subsequent offline cache
use; native PowerShell/Git dependency retry; GPU-family policy; source archives and
sprite hashes; cold model preparation; voice stop/start races; conversation and
microphone regression checks. Native UI, source/format checks, release payload and
CI validation are required before publication. Tests use isolated fixture data;
network fault injection does not reproduce every user's ISP or hardware conditions.
