# Capri v0.3.6

Pre-alpha. This release makes voice installation easier, adds communication
styles, and enables private update access directly inside Capri.

## Voice installation and recovery

- **Languages → Install and enable** now installs the selected voice into the
  current Capri installation. No terminal, voice ZIP extraction, destination
  folder or training is needed for the included voice.
- Fixed the old multilingual setup path that used the recognition interpreter
  without preparing the voice environment or importing its required profile.
  The compatibility command now prepares and uses the correct voice interpreter.
- Added in-app installation progress, cancellation, retry and diagnostic export.
  The panel can close and reconnect to an installation already in progress.
  It no longer sends users to an unexplained external setup console.
- Successful installation applies the selected language and enables speech
  automatically. It never enables microphone capture automatically.
- Non-English installation prepares the shared multilingual model and compatible
  voice dependencies without downloading unused English model weights first.
- Setup selects the matching voice from **Conversation language**. Friendly
  component/review labels replace the English-only primary voice label; manual
  voice-folder import remains an advanced option.
- The bundled Capri profile is retained even when installing in text-only mode,
  so it can be reused later. A retained bundled copy is kept outside editable
  voice exports; custom profiles are preserved.
- If the profile is missing, Capri can retrieve a checksum-verified release pack
  using authorized private GitHub access. The installer includes the same reviewed
  English adapter/reference pack as before; it is not a new voice-training release.
- Component installation shares the existing installer lock. Its owned Windows
  workers stop when Capri exits, with process start-time checks to avoid stopping
  an unrelated process that reused a PID.

## Conversation and character

- Added **Neutral, Romantic, Business and Wild** communication styles under
  **Companion settings → Conversation**. Selection saves automatically and applies
  to the next reply, without restarting models or clearing conversation.
- Simple questions and action confirmations now request one or two short, complete
  sentences. The default character avoids habitual follow-up questions, unsolicited
  romantic pet names and generic monologues about being an AI.
- Explicit requests for detail or longer fictional scenes remain supported.
  Replies are not silently regenerated or cut mid-sentence to enforce a word limit.
- Customized `PERSONALITY.md` files are retained. Only the reviewed, untouched
  older factory character is refreshed, with a backup. Communication style is a
  separate shared delivery preference, not a second editable character document.

## Private GitHub updates

- Added **Updates → Connect GitHub for private updates**, with an official GitHub
  token-creation link and instructions for read-only repository access. GitHub CLI
  is optional; existing CLI/environment credentials remain supported.
- Capri validates repository access before saving the token, then checks for
  updates. Failed replacement or cancellation preserves a working credential.
- On Windows, the token is encrypted for the local Windows account and remains in
  the main process. The renderer receives status only; the masked input is cleared
  after submission or panel close. Credential files stay out of diagnostic exports.
- Update/access controls prevent overlapping operations. Private-access failures
  now explain invitations, token permissions and organization approval instead of
  presenting an unexplained missing release.
- GitHub account/repository read access is still required. Fine-grained tokens
  require organization membership; GitHub's outside-collaborator limitation and
  token approval requirements are explained in the UI and documentation.

## Interface and hardware guidance

- Added explicit **system RAM**, **dedicated GPU VRAM** and **disk space**
  explanations in all 50 installer languages. Hardware detection labels show RAM
  and VRAM separately; documentation includes examples and model-planning tables.
  These resources cannot be added together or substituted for one another.
- Disconnected/disconnecting states now show Capri resting with closed eyes and
  animated zZz. Reconnection restores awake artwork. The technical connection and
  model power states remain accurate; resting artwork does not imply model unload.
- Added consistent hover/focus feedback to enabled buttons, including settings
  and update controls. Support buttons retain their pink styling; reduced-motion
  preferences disable the new transitions.

## Updating and downloads

Download **CapriSetup-0.3.6.exe**, close older setup windows and Capri, then select
your **existing installation folder**. Keep the existing model/package caches.
History, long-term memory, personal settings, custom Personality and downloaded
models are retained. Source checkouts remain separate from managed installations.

Older builds without the new private-access screen may need this one-time manual
installer update. Afterwards, private update checks can use the saved read-only
token. A token does not grant permissions the account does not already have.

The EXE includes Capri's source, sprites and English voice adapter/reference pack;
selected dependencies and base models still download during setup. The separate
**capri-en-v1.zip** asset is for advanced/manual use, not a prerequisite for normal
installation. **Capri-0.3.6-source.zip**, **BUILD_MANIFEST.json** and **SHA256SUMS.txt**
are also provided. The installer remains unsigned during pre-alpha.

## Validation

- 380 Node tests and 34 Python checks passed locally.
- All 400 installer pages rendered across 50 languages at 192 DPI.
- Native Electron checks covered style persistence, hover feedback, masked token
  entry, Windows credential encryption, disconnect/reconnect artwork, sleep/wake,
  settings confirmations and language/voice installation flows.
- Windows CI now activates its verification window before pointer input, matching
  normal app use instead of showing a hidden/non-focusable fixture mid-click.
  UI verification failures also record the active panel/modal state.
- Installer extraction verifies source hashes, all 68 artwork frames and the
  unchanged English voice pack.
- Private-auth checks used a fixture token with real Windows encryption. No
  subscriber credential or organization-policy change was used for testing.
  A fresh multi-GB model install and every supported GPU were not requalified by
  these fixture checks; network availability and actual hardware still matter.
