# v0.3.7 — local candidate

Prepared for manual review. No GitHub push, release publication or issue replies were made during this development batch.

## New capabilities

- Persistent reminders, countdown timers and stopwatches through the `time_control` tool and **Menu → Timers and reminders**. Pause/resume, elapsed/remaining time, cancellation, snooze, exact-time reminders and late delivery after restart. Timers continue while models are unloaded; live notifications require Capri to remain running.
- A fixed, authenticated local action broker and 90-second approval cards. Supported harmless settings can be changed conversationally. Disabled application/screen capabilities offer explicit next steps. Screen selection, model downloads and language/Spotify changes retain their dedicated controls.
- An opt-in local `.exe` application catalog with separate launch, accessible inspection and text-entry permissions. Text entry requires a fresh process/field inspection and on-screen approval, reads the value back and never sends Enter. Unsupported providers or ambiguous windows fail visibly.
- Single-file Recycle Bin operations in approved writable folders, always with an exact-path confirmation and verified recovery copy. File recovery never overwrites an existing destination. No shell command, unrestricted desktop control, directory deletion or permanent-delete fallback.
- Custom screen-analysis interval (15–300 seconds) and observation duration (0.5–120 minutes), saved separately from the temporary access lease.
- Optional fast automatic recognition for the 25 European languages supported by the pinned Parakeet v3 model. No draft transcription. English-only v2 and wider-language Whisper remain available. **Switching language inside a single utterance can omit words; reliable code-switching is not claimed.**

## Interface and character

- Compact signal-core dimming is bounded by visible companion controls rather than the unused portrait area. The expand/core toggle's color, label and pressed state now follow the visible state.
- Ordinary screen answers receive scene facts/freshness without capture dates, paths or source labels. Metadata remains available for explicit metadata questions and diagnostics. Screenshot-save receipts no longer inject a path into ordinary chat.
- The factory Personality explicitly uses she/her and feminine self-description where grammar requires it. Only reviewed unchanged factory defaults migrate; custom Personality files remain the owner's choice.
- All 50 interface catalogs include the new controls and substantive English fallback help was translated. Russian additions were reviewed directly; other machine translations remain open to native-speaker proofreading. No online translation runs in the installed UI.
- Timer notifications use a separate non-error surface, and new capabilities are marked BETA.

## Installation and reported failures

- Discover valid prior per-user managed installations. A single match is proposed automatically; multiple installations remain selectable without scanning arbitrary drives or following links.
- Finish launches the installed entry point, including installs whose model download was deferred. A per-launch acknowledgement verifies that a window appeared. Failure leaves the Finish page usable and records the cause instead of silently closing setup.
- The newest #8 archive identifies Windows error 1455 while loading English TTS. Loading now avoids the initialized duplicate of the native FP32 T3; the developer's fresh-process peak commit fell by about 2.0 GiB. The voice can still require more commit capacity than an individual system permits. A specific localized pagefile/memory message and process-bound diagnostic record replace the generic failure for this condition. Windows settings are never changed automatically.
- Available RAM, in addition to installed RAM, selects sequential model preparation under memory pressure without changing the chosen model.
- Repeated startup/show/model callbacks share one Windows-awareness startup rather than cancelling/restarting it. Observer failures are retained in diagnostics; the native cold-start deadline is bounded at 15 seconds.
- ASR packet rejection has content-free reason codes and diagnostic phase/wake/timing information. An old stop message is bound to its original microphone session; stale packets cannot fault a replacement capture.
- Open issues #11/#18 and the unproven portions of #19/#21 remain unresolved without fresh evidence. No speculative network/TLS or voice-quality workaround is presented as their confirmed fix.

## Verification and boundaries

The follow-up [open-issue audit](../issue-audit-2026-10-31.md) adds an intact-sentence
native FP32 retry for the speech-token limit reported in #23, content-free voice
failure codes, recovery of streamed wheel `network timeout` failures from #24,
and more tolerant child-process download timeouts/concurrency for slow links.
Locked dependencies, certificate/hash checks and explicit user settings remain.
Private-update denial now reveals the outside-collaborator guidance and an
explicit classic-token settings link; Read permissions are never changed by the
app. Download failures retain requested-host/stage/OS-code details without signed
URLs or credentials. Persistent network failures in #18/#25/#26 are not claimed
to be universally resolved.

This audit passed 429 Node tests, 46 targeted Python tests and native Electron
credential/UI checks. A separate real-weight probe injected one token-limit
failure, recovered complete non-silent 24 kHz PCM through native inference, then
used graph replay for the next sentence. It neither opened a second voice server
nor used the reporter's conversation or physical speakers.

Automated checks cover persistence/replay, monotonic clocks, daylight-saving ambiguity, current-process startup errors, concurrent observer startup, HTTP admission, consent/revocation, app/file action journaling and existing regressions. Native checks exercise actual desktop IPC, UI Automation text entry and Windows Recycle Bin using disposable files/windows. The wizard was checked across 400 pages / 50 languages at 200% DPI. Real local Qwen exercised both new time/settings tools in isolated conversations. Original FP32 weights and the trained adapter produced finite, non-silent 24 kHz audio after the loader change.

The developer PC is not a substitute for qualification on every GPU, low-memory system or microphone. The reported GTX 1650 machine still needs a user retest. AMD/NPU backend qualification, reliable within-utterance code-switching, arbitrary app providers and notifications while Capri is closed remain future work. See [behavior and limits](../timers-and-actions.md) and [speech measurements](../speech-performance.md).
