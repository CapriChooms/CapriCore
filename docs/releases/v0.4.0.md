# Capri v0.4.0

A major desktop update: redesigned settings, persistent reminders and timers,
more useful opt-in desktop actions, and fixes for voice, microphone, initiative,
installation and private-repository updates. This release includes the work
previously reviewed locally as the unpublished v0.3.7 candidate.

Capri remains **pre-alpha**. Features marked BETA can still have rough edges.

## Download and update

- Download **CapriSetup-0.4.0.exe** below. It includes Capri's sprites/animations and
  the ready English Capri voice adapter; no separate voice ZIP import is needed
  for a normal installation.
- Close older setup windows and select your existing Capri installation to update.
  Setup now discovers valid earlier managed installations. Existing conversation,
  memory, settings and verified downloaded models are retained.
- Choose the conversation and spoken language in setup or **Settings → Languages**.
  The language page offers voice installation/repair directly. The small bundled
  English voice pack is an adapter, not the large base speech model: setup still
  downloads the selected public models and dependencies.
- **Capri-0.4.0-source.zip** contains the reviewed source. **capri-en-v1.zip** is also
  attached for manual voice import/repair; it is already bundled in Setup.
  **BUILD_MANIFEST.json** and **SHA256SUMS.txt** describe the release files.

## Redesigned settings and interface

- The gear opens one reusable, separate Cyberpunk settings panel with **17
  categories and search**. It prefers the left of Capri, follows the companion
  while docked, initially matches its height and stays within the display's work
  area. Settings no longer cover the main toolbar or sit behind startup progress.
- Removed the redundant ellipsis menu, obsolete toolbar controls and duplicate
  OBS badge beside the title. Dedicated quick controls remain on the toolbar.
- Unsaved settings have clear stay/discard/apply choices. Concurrent edits from
  another window cannot silently overwrite a newer saved preference.
- Buttons, sliders and scrollbars share the Cyberpunk styling. Hover uses glow
  and color without the rectangular outline; keyboard focus stays visible.
  BETA badges are styled consistently, including custom applications.
- Error notifications now offer **Dismiss** beside **Report a bug**.
- Restored continuous in-window sprite dragging: echoed position updates no longer
  cancel the active pointer gesture. Portrait zoom now reaches **300%**.
- Compact signal-core dimming follows the visible controls instead of retaining
  the full portrait's shadow. The expand/core button's color, label and pressed
  state match the actual mode.
- Portrait and window borders share the glitch schedule, including the settings
  window. Glitch controls explain enable, strength, interval, action bursts,
  preview and reduced motion. Button-press feedback has its own description and
  switch; it is independent of glitch effects.
- The support heart stays centered in its orbit. The support page identifies
  Overyx as the developer and keeps the TikTok button uncluttered.
- All **50 supported interface languages** cover the new controls, help, errors
  and native-dialog labels. Multiline help resolves consistently; the portrait
  footer is localized too. Filenames, model identifiers, logs and conversation
  are user/model data, not interface text. Native-speaker translation feedback
  is welcome.

## Voice, microphone and conversation

- Fresh profiles use a **1-second** end-of-speech pause. Existing saved values are
  preserved. Microphone choices show the real source names, system default and
  disconnected saved devices; selecting a device saves independently.
- Wake acknowledgements use the selected Capri voice and spoken language. The
  cache refreshes after preparation from either window and is keyed to the voice,
  language and phrase. An unavailable selected voice no longer silently becomes
  the signal tone. Spoken acknowledgements feed the echo guard correctly.
- When a **voice-origin** reply ends in a question, follow-up Listening can open
  after playback in the same enabled microphone session. A typed message never
  turns on microphone capture. Existing follow-up expiry and microphone-off
  protections remain in place.
- Added optional **Fast auto** recognition for Parakeet v3's 25 European languages.
  Accurate English Parakeet v2 and wider-language Whisper remain available;
  recognition does not reintroduce a low-quality draft transcript.
- Old microphone stop messages and delayed audio packets are bound to their
  original session, so they cannot fault a newly started microphone. Diagnostic
  reason codes make rejected audio easier to investigate without recording it.
- The optional **Synthetic** voice effect adds adjustable electronic ring
  modulation after synthesis. Clean voice remains the default.
- Reduced English TTS startup memory peaks by avoiding an unnecessary initialized
  FP32 model copy. Preparation becomes sequential under available-RAM pressure.
  Windows commit/pagefile error **1455** now has a specific diagnostic instead of
  a generic voice failure. Windows memory settings are not changed automatically.
- Fixed recovery from the Turbo speech token-limit failure reported in **#23**:
  one bounded retry synthesizes the **whole sentence** through native FP32
  inference, then restores CUDA-graph replay. It does not emit partial audio or
  silently skip words. Cancellation and unrelated failures are not retried.
- Voice health and desktop diagnostics retain bounded error/status codes without
  including the spoken sentence, credentials or arbitrary service response text.
- Factory personality uses she/her and feminine grammar where needed. Short
  practical requests get concise replies without habitual follow-up questions.
  Reviewed factory defaults can migrate; custom Personality files stay editable
  and are not replaced with a new character.
- Disconnection shows Capri asleep with closed eyes and animated Zzz while
  preserving the real connection/model state.

## Reminders, timers, stopwatch and initiative

- Added persistent reminders, countdown timers and stopwatches via conversation
  and **Settings → Timers and reminders**: elapsed/remaining time, pause/resume,
  cancellation, snooze and exact-time reminders. Restart catch-up and ambiguous
  daylight-saving times are handled explicitly.
- Stopwatch answers read fresh elapsed time rather than repeating an earlier
  value. A small digital display appears at the top of Capri; click it for
  pause/resume, reset, stop and the full timer list. Reset preserves its identity
  and running/paused state.
- Due reminders can reveal Capri and prepare the selected voice to deliver the
  reminder even after model unloading. Mute, text-only, lock and busy states are
  respected; failed voice delivery can be retried separately from notification.
- Fixed initiative being postponed indefinitely by microphone activity. The first
  eligible attempt is earlier, recent conversation gets a grace period, and
  conversational mode has bounded retries after silence. Quiet hours can now be
  disabled. Fullscreen, typing, speech and hourly limits remain effective.
- Initiative status and a test action make blocking conditions visible. Repetitive
  greetings and internal system-event wording are filtered from voluntary replies.

## Opt-in applications, files and screen observation

- Added a configurable local **.exe application catalog** with separate grants
  for launch, accessible inspection and text entry. Exact executable identity,
  fresh window/control inspection and explicit confirmation protect mutations.
  Text entry verifies the result and never automatically sends Enter.
- Added confirmed HTTP(S) navigation for approved **Chrome/Edge** installations.
  Missing/aliased tool identifiers can be recovered only from one unambiguous
  current capability. Stale or ambiguous targets require a fresh inspection.
- Conversational changes to supported harmless settings go through a fixed local
  action broker. Disabled screen/application capabilities offer an explicit
  permission step; a model cannot grant itself access.
- File tools support scoped listing, search, reading, creation, copy, move, rename
  and undo. Replacing existing text requires a fresh content hash, confirmation
  and a private backup; creation never quietly overwrites an existing file.
- Single files in approved writable folders can go to the **Windows Recycle Bin**
  with exact-path confirmation and a verified recovery copy. Each folder now has
  its own red **Revoke access** control; revocation invalidates pending approvals.
- Recovery copies can be permanently removed after a **3-second confirmation**
  enforced by the backend. This deletes Capri's recovery copy only; restored
  originals and the Windows Recycle Bin are separate. This is not secure erasure.
- Different pending mutations form a bounded confirmation queue. Duplicate
  proposals reuse the current request; delayed confirmation cannot cancel or
  approve the next action accidentally. Actions remain journaled.
- Screen analysis interval is configurable from **15–300 seconds**, and observation
  duration from **0.5–120 minutes**. While observation runs, these fields are gray
  and explain that monitoring must be stopped first; backend checks agree.
- Ordinary screen replies use current scene facts without injecting capture
  filenames, timestamps or paths. Explicit metadata questions still work.
  Screenshot-save receipts no longer put the saved path into ordinary chat.
- Windows app awareness now shares one startup across concurrent show/restart/model
  callbacks, retains native failures and allows a bounded 15-second cold start.

## Installer, downloads and private updates

- Finish launches the installed entry point even when model download was deferred.
  A per-launch acknowledgement checks that a window appeared. Failures leave
  Finish usable and preserve the cause instead of closing silently.
- Recognized streamed-wheel **network timeout** failures now retry correctly
  (**#24**), including failures reported during extraction.
- Slow speech-dependency downloads get child-process defaults of **30 seconds to
  connect / 120 seconds idle read**. Package-network retries reduce concurrency
  from eight downloads to two, then one (**#25**). Explicit user settings are
  respected, caches are reused, retries stay bounded and cancellation works.
- Model-download errors include the requested host, transfer stage and numeric OS
  error without exposing signed URLs or private exception text (**#26**).
  Certificate, checksum and dependency-pin verification remain enabled.
- Private-update failures expand GitHub access guidance and provide an explicit
  classic-token settings link for outside collaborators (**#27**). A scoped
  read-only fine-grained token remains preferable for organization members;
  outside-collaborator access is a GitHub limitation of fine-grained tokens.
  Credentials stay encrypted, failed replacement keeps working access, and
  subscriber permissions are never changed by Capri.
- Updated native UI verification to exercise the actual separate settings window
  rather than the removed in-window forms.

## Verification and remaining limits

The local candidate passed **429 Node tests**, targeted Python voice/download
regressions, isolated native Electron/settings/credential checks and disposable
Windows application/file-action checks. The installer has also been rendered
across all 50 languages. A controlled real-weight GPU recovery probe produced
complete finite, non-silent 24 kHz audio and confirmed graph replay on the next
sentence. It did not use a reporter's conversation or prove behavior on every GPU.
The maintainer completed manual review before publication.

- **Local TTS still requires a supported NVIDIA CUDA setup. AMD/NPU TTS is not
  introduced in this release.** Available RAM, VRAM and Windows commit capacity
  still matter; reducing startup peaks cannot make every low-memory PC suitable.
- Reminders require Capri to be running and Windows awake; recurring schedules
  and notifications while Capri is closed are not included.
- Reliable language switching inside one utterance and unrestricted browser or
  desktop automation are not claimed. Text entry depends on the application's
  accessible controls and explicit grants.
- Persistent DNS failures, blocked hosts and interrupted network paths cannot be
  solved by retries alone. Reports **#18, #25 and #26** need reporter retests;
  these changes are not presented as universal network fixes. The older hardware
  and observer reports also need confirmation on the affected machines.
