# Capri v0.4.3

This pre-alpha update improves response speed and fixes several interface problems.

- Faster conversation handling: reuse Qwen's prompt cache more consistently and compact oversized active conversations earlier, without deleting saved history or memory.
- Choose a 32K, 64K, 128K or 256K context window in Qwen settings. The new CTX meter shows the latest known usage; click it to open those settings. Larger contexts need more memory and can be slower.
- Settings waits for its content to render before appearing. Improved first-open, tray restore and shutdown behavior; saved application permissions now appear correctly after restarting.
- Clearer button-press feedback, a working preview and synchronized on/off settings across both windows.
- Slow speech/model installation steps now allow up to eight active hours instead of one. Download failures show the underlying Node connection error instead of a generic “Wait” exception. Network retries, cancellation and checksum verification remain in place.

**Download CapriSetup-0.4.3.exe.** To update, select your existing Capri folder; history, memory, settings and downloaded models are preserved. If an older in-app updater cannot open its update window, close Capri and run this installer manually.

The installer includes sprites and the English voice adapter. Larger speech dependencies and base models still download during setup. `capri-en-v1.zip` is for manual voice-pack import; `Capri-0.4.3-source.zip` is the source payload. The Windows installer is unsigned; checksums are in `SHA256SUMS.txt`.

Reported network failures, animation freezes and response timeouts without sufficient diagnostics remain under investigation. This release does not claim to resolve every such report or introduce AMD/NPU voice support.
