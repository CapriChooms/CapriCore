# Capri v0.4.4

This pre-alpha update improves setup reliability and adds optional ways to run and use Capri.

- Voice setup recovers from more interrupted TLS downloads and shows live model-download bytes, speed and waiting status. Runtime HTTP/schema libraries receive security patches.
- Screen questions capture a fresh frame. Clearer application launch instructions, more reliable Windows focus handling and conversation routing that prevents greetings from starting app-control loops.
- Optional external AI providers with streaming/tool support and Windows-encrypted API-key storage.
- Experimental AMD ROCm speech, plus optional Ministral 3 and Gemma 4 language models. Qwen remains the default.
- Owner-enabled computer control: observed targets, key combinations/holds, mouse input, visible indicators and Escape cancellation. Full-computer access requires a separate three-second confirmation.
- Optional Discord activity and updated interface/setup translations across all 50 languages. An animation production plan is included in the source documentation.

**Download CapriSetup-0.4.4.exe.** Select your existing Capri folder to update; personal settings, memory, history and downloaded models are retained. The installer includes sprites and the English voice adapter; larger dependencies and base models still download during setup. Checksums are in `SHA256SUMS.txt`; the Windows installer is unsigned.

AMD speech is **experimental**, limited to the documented Windows 11/ROCm hardware matrix. Packages and imports were tested, but Radeon synthesis requires hardware validation. Discord activity needs a registered Discord Application ID and image asset. External API use requires your own compatible provider/account and may incur charges. Unconfirmed network, timeout and GPU-freeze reports remain under investigation.
