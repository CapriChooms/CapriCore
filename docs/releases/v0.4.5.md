# Capri v0.4.5 — Experimental

Experimental pre-alpha build for testing. Keep a backup of your personal data before trying it.

- Installer: the desktop runtime now downloads and verifies inside Setup, with pause/resume; better network recovery. Gemma 4 E2B and Ministral 3 3B (BETA) include RAM requirements and estimated VRAM recommendations in all 50 languages.
- Lighter startup: microphone and voice start off. Their models load when enabled, and switching them off releases their memory.
- Computer control: improved app discovery, verified browser input/search, and an observe–act loop with Escape cancellation and honest incomplete-task results.
- More capable scientific calculator, Spotify volume confirmations, folder discovery and voice recovery fixes.
- Cleaner window settings, softer dimming edges, resource rings, and a shared microphone/zoom/resource row without layout jumps.
- Screen capture tolerates a transient frame failure and records startup failure stages without saving screen content.

Download **CapriSetup-0.4.5.exe**. Sprites and the English voice adapter are included; base models and dependencies download during setup. Select an existing Capri folder to update. Checksums: **SHA256SUMS.txt**. Installer is unsigned.

AMD speech and alternative models remain BETA. Regional download failures, unconfirmed startup reports and hardware-specific issues are not claimed universally resolved. This release does not replace the stable update channel.
