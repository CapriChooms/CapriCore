# Capri v0.4.6 — Experimental

Experimental pre-alpha. This build improves computer control; complex tasks can still need help.

- Better browser task sequences: real page search fields, verified submission, clearer completion checks and safer app/window selection.
- Smooth mouse movement and drag-and-drop; taskbar app targets and a control frame covering the complete monitor. Improved text entry in Chromium and older Qt apps.
- Basic Resolve timeline assembly via its local scripting interface, with verified source ranges and adjacent cuts.
- Procedural Capri/Blackwall edge effects, cursor trail, intensity and motion settings, with a preview. Esc stops control; losing the indicator also stops input.
- Clearer RAM/VRAM estimates in Setup and model selection, plus application discovery, microphone, update-access and technical-response fixes.

Download **CapriSetup-0.4.6.exe**. Sprites and the English voice adapter are included; dependencies and base models download during installation. Check **SHA256SUMS.txt**. The installer is unsigned. This release stays on the experimental update channel.
