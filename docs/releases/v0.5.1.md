## Capri 0.5.1

- Explicit memory requests now save locally and can be recalled after restarting Capri. [Issue #57](https://github.com/CapriChooms/Capri/issues/57)
- Voice installation shows when it is connecting or retrying, and reports unsupported GPUs more clearly. [Issue #52](https://github.com/CapriChooms/Capri/issues/52)
- Completed interface and installer translations across 50 languages. Fixed language switching with missing voices and microphone layout shifts in narrow windows.

Download **CapriSetup-0.5.1.exe** for Windows. To update, select your current Capri folder in Setup.
