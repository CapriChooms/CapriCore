## Capri 0.6.0

- Cyberpunk installer, API/Hugging Face model selection, and interface translations across 50 languages.
- Smoother desktop movement and an option to skip local LLM startup when using an API.
- Clipboard attachments, image previews in Conversation, and reply history above Capri.
- Task-specific Thinking introductions and music animations that follow the track BPM.
- Fixed Voice Calls reply sharing, microphone quality, and virtual microphone playback.
- Computer-control, image-reply and uninstall fixes, plus bundled dependency security updates.

Download **CapriSetup-0.6.0.exe** for Windows. To update, select your existing Capri folder in Setup.
