# Capri v0.6.1

- Added a separate, saved **Voice calls** volume control for Capri (0–100%, default 50%). Changes apply during speech without changing microphone or local playback volume.
- Added one conservative restart after a native speech-model loading crash. Improved voice-download status, language selection and unsupported-GPU messages, with a CPU voice alternative.
- Fixed detached avatar dragging after a perched window is restored, delayed hitboxes on teleport arrival, and music poses resetting during dragging.
- Stabilized the floating input bar during window movement and display scaling. Moved the reply arrow beneath the status and kept the compact signal core to its toolbar.
- Removed a canned personality example that small models could repeat, clarified muted audio states, improved the busy model selector and corrected installer byline scaling.

New call-volume controls are translated into all 50 interface languages. Update with **CapriSetup-0.6.1.exe**; the installer supports existing installations.

The download-status fix does not add Chatterbox support to unsupported GPUs. Native speech-crash recovery was tested with an injected failure and real English/Russian model startup; the original user-specific crash was not reproduced. Call audio was verified with synthetic signals and Chromium audio processing; a physical VB-CABLE call remains a separate hardware check.
