The Windows installer is unsigned. The macOS app is ad-hoc signed and is not notarized. See the [Linux](https://github.com/CapriChooms/CapriCore/blob/main/LINUX-PREVIEW.md) and [macOS](https://github.com/CapriChooms/CapriCore/blob/main/docs/macos.md) guides for system requirements and platform limits.

## Avatar and voice

- New layered facial animations and an Avatar Gallery to preview poses, expressions and motion.
- Music reactions keep Capri's current pose. Sleeping poses breathe slowly, and idle expressions can change on their own.
- Teleport travel time is adjustable. Capri appears at her destination while the lightning finishes.
- Spoken replies have output gain and pitch controls. Enable **Spoken replies** after installation to hear the selected voice.
- Load local models from the main window when needed. Automatic unloading and the idle timeout are configurable.

## Desktop and updates

- Steam tasks can recover focus through the observed Steam taskbar button when Windows refuses a direct focus request.
- YouTube requests can start in the browser even when the initial desktop observation is unavailable. Recommendations use videos observed on YouTube.
- Chess draws the board frame and Stockfish arrows on detected digital boards across sites.
- Setup can repair an installation or add components. The **Location** step offers an optional reset of desktop preferences.
- Patch notes appear on the first launch after an update and are available again from Help.
